## 2026-09-13 夜：SHP + 数据表 + 字节码全部破解 ✅（M0 主体完成）

### 1. SHP/TLHS 精灵格式（完全破解，修正此前的"RLE"猜测）

```
+0x00  'TLHS' + 4 字节 0   魔数
+0x08  u32 = 2
+0x10  u32 = 透明键色（Portrait=0xFFFF；UI 可能=0x07E0 纯绿）
+0x14  u32 = 宽
+0x18  u32 = 高（同时=帧数）
+0x24  起为帧偏移表（u32 × 高）
帧数据: [u16 flags][u16 本行宽度][RGB565 小端像素 × 宽]
```

- **不是 RLE，是 RGB565 直色**（每像素 2 字节）→ 解释了 PAK 内无任何 `.pal`/调色板文件

### ⚠️ 关键坑：vcvars64.bat 不可用，必须手工构造环境

- `vcvars64.bat` 内部调用 **`reg.exe`，被沙箱安全策略拦截**（Program Blacklist），

- **解法（已固化为 `tools/msvc_env.py`）**：手工拼 PATH / INCLUDE / LIB：
  - PATH ← `{VC}\bin\Hostx64\x64` + `SDK\bin\{ver}\x64`
  - INCLUDE ← `{VC}\include` + `SDK\Include\{ver}\{ucrt,shared,um,winrt,cppwinrt}`
  - LIB ← `{VC}\lib\x64` + `SDK\Lib\{ver}\{ucrt,um}\x64`
- 验证结果：**C 编译+运行 OK，C++（含 STL vector/string）编译+运行 OK**。
- **规矩：所有需要编译的脚本一律 `from msvc_env import make_env, run`，禁止再 call vcvars64.bat。**
- 注：`{VC}\include` 下没有 stdio.h 是正常的（C 标准库头在 SDK ucrt 里），不是缺组件。
