## 2026-09-13 夜：SHP + 数据表 + 字节码全部破解 ✅（M0 主体完成）

### 1. SHP/TLHS 精灵格式（完全破解，修正此前的"RLE"猜测）

```
+0x00  'TLHS' + 4 字节 0   魔数
+0x08  u32 = 2
+0x10  u32 = 透明键色（Portrait=0xFFFF；UI 可能=0x07E0 纯绿）
+0x14  u32 = 宽
+0x18  u32 = 高（同时=帧数）
+0x24  起为帧偏移表（u32 × 高）
帧数据: [u16 flags][u16 本行宽度][RGB565 小端像素 × 宽]
```

- **不是 RLE，是 RGB565 直色**（每像素 2 字节）→ 解释了 PAK 内无任何 `.pal`/调色板文件
- 每帧 = 一行像素。Portrait：100×120，每帧 4B 头 + 200B 像素，帧长定长 206B

### ⚠️ 关键坑：vcvars64.bat 不可用，必须手工构造环境

- `vcvars64.bat` 内部调用 **`reg.exe`，被沙箱安全策略拦截**（Program Blacklist），
  表现为：cl.exe 在 PATH 里能找到，但 INCLUDE/LIB 为空 → `fatal error C1083: 无法打开 stdio.h`。
- **解法（已固化为 `tools/msvc_env.py`）**：手工拼 PATH / INCLUDE / LIB：
  - PATH ← `{VC}\bin\Hostx64\x64` + `SDK\bin\{ver}\x64`
  - INCLUDE ← `{VC}\include` + `SDK\Include\{ver}\{ucrt,shared,um,winrt,cppwinrt}`
  - LIB ← `{VC}\lib\x64` + `SDK\Lib\{ver}\{ucrt,um}\x64`
- 验证结果：**C 编译+运行 OK，C++（含 STL vector/string）编译+运行 OK**。
- **规矩：所有需要编译的脚本一律 `from msvc_env import make_env, run`，禁止再 call vcvars64.bat。**
- 注：`{VC}\include` 下没有 stdio.h 是正常的（C 标准库头在 SDK ucrt 里），不是缺组件。

### ⭐ 破解装备加成机制（本次最重要的数据发现）

- `General01.ini` 三个装备槽 **`Weapon` / `Book` / `Horse`** —— 存档值是**物品名字符串**
  （如 `曹操 Weapon=吳鉤`、`呂布 Weapon=月牙戟`），**不是索引**（早期误用 `to_int` 读成全 0）。
- `Thing.ini` 的 **`Increment` / `Increment2` / `Increment3`** 是加成值，语义由 `Statement` 逐件校准：
  - **Type=2 武器（41 件）→ Increment1 = 武力 +1~+20**（方天畫戟+10、干將/莫邪+16、**奧汀神槍+20 为上限**）
  - Type=3 书（10 件）→ 智力 / 技力上限 / 体力上限（逐件不同，**不加武力**）
  - Type=4 马（26 件）→ 速度上升（部分 Increment2 为特性位，**不加武力**）
- **攻击力公式：`当前攻击力 = 基础武力 + 武器加成`**（书与马不参与）
- 推论：基础武力 ≥ `80−20 = 60` 的武将理论上都能靠武器跨过 80 → 覆盖原版绝大多数武将。

### 内置开源中文字体（OFL-1.1）✅ —— 含一次重要的选型修正

**初选（错误）**：霞鹜文楷 + 方舟像素 ArkPixel12。渲染验收图时发现「必**殺**技」的"殺"显示为**方框**，
于是用**游戏自身全部文本**（16 个 INI）提取出 **1970 个不同汉字**，逐个比对字体 cmap：

| 候选 | 内码位 | 缺失 | 覆盖率 | 结论 |
|---|---|---|---|---|
| Ark Pixel 12px | 24,471 | 158 | **92.10%** | ✗ 弃用 —— 缺的是高频字 孫/殺/擊/旋/拖/換/應/懷/錢 |
| Ark Pixel 16px | 3,252 | 1909 | 3.10% | ✗ 该档位覆盖不全 |
| **Fusion Pixel 12px**（缝合像素） | 36,558 | **3** | **99.85%** | ✅ 采用 |
| **LXGW WenKai**（霞鹜文楷） | 46,490 | **0** | **100%** | ✅ 采用（默认） |

**实际部署**（`engine/assets/fonts/`，合计 31.1MB，随仓库分发）：
- `LXGWWenKai-Regular.ttf` 霞鹜文楷 v1.522（25.6MB）—— **高清模式默认**，覆盖 100%
- `FusionPixel12-zh_hant.ttf` 缝合像素 12px（7.0MB）—— **像素模式**，取 zh_hant（游戏是 Big5 繁体）
- `OFL-FusionPixel.txt` / `OFL-LXGWWenKai.txt` + `README.md`（来源/覆盖率表/再生成方式）

**⭐ 像素模式必须配字体回退链**：FusionPixel12 缺的 3 个字是 **繇 / 鋻 / 鎩**，
全部在真实文本里（劉**繇**=武将名、**鎩**=武器名、"實**鋻**此心"=桃园结义剧情）。
→ 引擎用 `TTF_AddFallbackFont(pixelFont, wenkaiFont)`，缺字自动落到楷体，**任何文本都不出方框**。

**教训（已写入架构文档）**：**字体覆盖率必须用真实文本量化，不能凭感觉选**。
Ark Pixel 是知名开源像素字体，观感也好，但覆盖率不足以支撑本项目的繁体文本。

`tools/render_font_preview.py`（渲染验收图，含回退验证）

### ⚠ 环境陷阱：PYTHONPATH 劫持 pip 安装位置

- 环境变量 `PYTHONPATH` 含 `D:\PythonPackages\site-packages`，**所有 `pip install` 都装到那里**，

- **不要用 `python -E` 运行需要第三方库（PIL/fonttools）的脚本** —— `-E` 会忽略 PYTHONPATH，
  反而找不到包。直接用原始解释器即可。
