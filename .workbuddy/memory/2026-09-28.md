## 五、踩坑（已补充进项目约定）

- ⭐ **叠加层处理块的插入位置会"吞掉"视图切换**：外交叠加层放在 `else if (g_admin_map)` **之前**并
  `continue` → `diplo_start` 设的 `g_admin_map = 1` 永不被消费 → **界面停在朝堂、看不到选国家**。
  修法：在该块开头先消费 `g_admin_map`（`if (g_admin_map) { g_admin_map = 0; if (court) mode = 4; }`）。
  （教训同族：**事件处理块的顺序 = 隐式优先级**，新增块要明确自己"在谁之前/之后"。）
- **地图视图里的选择器是 z=2**（`cv_map` 宽 1024 > 640）→ 面板与行高都 ×2；
  朝堂 UI 层（640）才是 z=1。**量坐标前先确认画布宽**（本轮白点了一次）。
