## M2 收口 + M4 启动

### 段错误排查与修复（重要）
出图 `[20000]`（Statusbar）时 `sango3menu` **段错误**。排查路径：数据无异常字段、
`canvas_blit` 有边界检查 → 根因在 `shp.c`：
`size_t avail = (size_t)(end - off - FRAME_HDR) / 2;` 当 `end - off < 4` 时按 size_t
**下溢成巨大值**，`span` 因此不被裁剪 → **越界读内存** → 段错误。
修法：先做有符号判断 `end >= off + FRAME_HDR`，不足则 `avail = 0`（该行留空），绝不越界。
回归：`verify_data_c` **9024 项** + `verify_ui_c` **11530 项** 全过。
> 注：`verify_shp_c.py` 本次样本数为 0（样本文件缺失），需重建样本后补跑该回归。

## M4 完成：主菜单在安卓跑通 🎉

### 结果
- **`sango3.apk` 在雷电模拟器正常运行**：主菜单（背景 + 5 按钮 + 版权行）的颜色与布局与 PC 一致。
- 链路：NDK CMake 编 `libmain.so`（含 SDL2 一并编译）→ aapt2 → javac → d8 → 组装
  → zipalign → apksigner。
- 复现：`python tools/build_android.py --install`

### 九个坑（详见 `docs/Android构建.md`）
1. CMake 找不到 ninja → 传 `-DCMAKE_MAKE_PROGRAM`
2. `Cannot find source file: E:/engine/src/pak.c` → 相对路径层级（`android/app/jni` 上溯**三级**）
3. 脚本 `shutil.rmtree` 被安全策略拦截（`SAFE_DELETE_BULK_CONFIRM_REQUIRED`）→ 改 `dirs_exist_ok` 增量覆盖
4. `AndroidManifest.xml: must have a 'package' attribute` → 构建时注入 `package="org.libsdl.app"`
5. `android.jar: No such file` → sdkmanager 未装完，从 `repository2-3.xml` 查真实 zip（`platform-34-ext7_r03.zip`）直下
6. javac 报"编码 GBK 的不可映射字符" → SDLActivity.java 含 emoji，加 `-encoding utf-8`
7. d8 报 `UnsupportedClassVersionError ... 55.0` → 用的是系统 JDK 8；**子进程显式设 `JAVA_HOME`=JDK17**
8. 启动报 `couldn't find "libSDL2.so"` → APK 要把 `build/native/**/lib*.so` 全部打进 `lib/<abi>/`
9. 进程秒退（日志 `Finished main function`）→ 资源在公共 `/sdcard/` 需运行时权限；
   改用**应用外部私有目录** `/sdcard/Android/data/org.libsdl.app/files/Sango3/`

### 两条非报错型坑
- **通道错位**：`RGBA8888` → 整屏**偏红**（alpha 落到 R）；`BGRA8888` → 整屏**偏蓝**（alpha 落到 B）
  → 推断 GLES 后端的打包格式通道顺序相对 SDL 定义是**反转**的 →
  **Android 用 `SDL_PIXELFORMAT_ABGR8888`**（PC 仍用 `RGBA8888`）。
- `__android_log_print` 未定义 → 需 `target_link_libraries(... log)`。

### 调试手段（有效）
- 加 `ALOG(...)`（`__android_log_print`）把关键分支打到 logcat；
  `adb logcat -d | grep -E "sango3|SDL"` 直接看到 "app started" 或失败原因。
- `adb exec-out screencap -p` 截图核对画面（比描述可靠）。

### 遗留
- **字体**：SDL2_ttf + FreeType 需纳入 NDK 构建才能显示文本。
- **EXTEND** 宽高比（手机长屏利用宽度）未做。
