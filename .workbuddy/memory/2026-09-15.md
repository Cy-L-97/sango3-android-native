## M4 遗留收口：安卓字体（FreeType 直连）—— 进行中

### 决策：不用 SDL2_ttf，font.c 新增 FreeType 直连后端
- 理由：SDL2_ttf 的 CMake 会拉 harfbuzz / plutosvg，NDK 交叉编译链路长；
  FreeType 是纯 C 单库，add_subdirectory 即编。两个后端对外接口一致
  （`SANGO3_HAVE_TTF` / `SANGO3_HAVE_FREETYPE`，font.c 内 #ifdef 分支）。
- FreeType 2.13.3 源码下载自 savannah（github tag 名不对会 404；savannah 可达）
  → `third_party/freetype-2.13.3`（third_party 不入库）。
- 可选依赖全关：`FT_DISABLE_{ZLIB,BZIP2,PNG,HARFBUZZ,BROTLI}=ON`。

### 改动清单
- `engine/src/font.c`：重构为「公共区（字体目录 + pick_font_path）+ 两个后端分支 + 空实现」；
  FreeType 分支：FT_New_Face + Set_Pixel_Sizes + 两遍渲染（先量尺寸再贴字形），
  像素模式 `FT_LOAD_NO_HINTING|FT_LOAD_NO_AUTOHINT`，灰度 bitmap 直接当 alpha。
- `android/app/jni/CMakeLists.txt`：glob 找 `third_party/freetype-*`（版本升级免改），
  定义 `SANGO3_HAVE_FREETYPE=1`，链接 freetype。
- `tools/build_android.py`：sync_sources 增同步 freetype（首次复制）；
  新增 `--push-assets`（推 encoding + fonts 到设备私有目录；可单跑）。
- `docs/Android构建.md`：更新字体方案与命令。

## 用户实测反馈的两 bug 修复（20:22 实机验证通过）

### ① 场景重叠（主菜单上叠着登录武将界面）
- **根因**：`s3_menu_render` **不清画布**，sango3app 每帧复用同一画布。
  子场景（登錄武將=面板+列表框架）不是全屏 → 上一场景（主菜单）像素全部残留。
  之前没暴露：M2-7 场景验证走 sango3menu 离线出图（每次新画布）。
- **修法**：`s3_menu_render` 开头 `sango3_canvas_fill` 清黑（"渲染一个场景 = 一整帧"语义）。

### ② 不能返回（安卓无右键）
- **修法**：`SDL_HINT_ANDROID_TRAP_BACK_BUTTON=1`（presenter_new 前设置，拦下系统默认退出）
  → presenter 事件循环把 `SDLK_AC_BACK` keydown 转成 `ptr_rclick` 边沿 → 走既有"右键返回"逻辑。
  实测：主菜单点「读取進度」→ 13 roots 存档场景（**无残留**）→ Back → 干净主菜单。

### ③ 顺手修：快速点按整次丢失
- 原判定 `if (pt.ldown && !prev_down) press=hit` + `if (!pt.ldown && prev_down)` 触发
  —— **同帧 down+up**（adb input tap、极快点击）时电平判定整次丢失。
- 改为：`if (pt.lclick) press=hit`（按下边沿即记录）+ `if (!pt.ldown && press)` 触发。

### 调试手段
- Android 上 printf 不进 logcat → 关键分支加 ALOG（input 边沿 / scene 切换 / content rect）。
- adb 自动化验证：`input tap x y` + `input keyevent 4`（BACK）+ screencap 三连，可无人值守回归。
- 模拟器窗口实测 **1080×1848 竖屏**，内容矩形 `0,519 1080x810`（scale=1.6875）；
  注意 `input tap` 注入坐标与 presenter 反算有 ~72px y 向偏差（原因未查，不影响真机操作）。

## 子窗口相对坐标 bug（用户框出三处别扭 → 同一根因，20:45 修复）

- **根因**：INI 里**子窗口的 Range 是相对父窗口**的，渲染与命中测试都当绝对用了。
  证据：410 列表的表头子按钮 (10,6)/(83,6)/(209,6)... 以金框宽 501 为界自洽递增；
  按绝对渲染整体左上错位 (129,9)，表头压住页签、滚动条悬空在右上/右下。
- 主菜单之前没暴露：root 1 在 (0,0)，相对=绝对。**凡父窗口不在原点的都错**。
- **修法**：draw_window / hit_rec 均加 ox,oy 累计父偏移；
  子递归传 (ax,ay)；icon 贴图 = ax+pos。单 root 模式把 root 平移到 (0,0)。
- 回归：verify_ui_c **11530 项全过**；PC 出图 login_ui3 + 横屏实机 ls_login2 均正常。
- 提交：`2d418dc`（登录场景+ICON_ONLY）之后本次为坐标修复提交。
