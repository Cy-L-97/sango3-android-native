## 一、待修 Bug

> **当前无待修 Bug**。下面两条已于 2026-09-17 修复并**实机验证通过**（复测记录见文末）。

### BUG-1 ★高：武将选择窗列表为空（**已修 + 已验证**）

- **现象**：点我方城池后弹出"選擇執行者"窗，列表空 → 无法执行任何指令。
- **根因（现场复核后确认，比原记录更严重）**：`sango3app.c` 进战略层时
  **名册（roster）的创建/清空写在 `load_cities()` 之后**（原第 1216~1217 行），
  而 `load_cities()` 内部才逐将 `s3_roster_add()` 装名册、末尾 `s3_roster_mark_city()` 标归属。
  于是：
  1. **首次进入**：`g_roster` 还是 `NULL` → `load_cities` 里所有 `if (roster)` 分支全跳过
     → 名册一条都不装；
  2. **重开局**：名册已存在，但 `clear` 在装完之后 → **刚装好的名册被清空**。
  两条路都让 `s3_roster_workers()` 返回 0。
- **修法（已实施）**：把 `new/clear` 整体提到 `if (kd) { … load_cities(…g_roster) … }` **之前**；
  并加日志 `roster: N officers` + 逐城 `roster: N officers / M idle in <城>`（logcat 可复核）。
- **离线预期值**（`tmp/roster_probe.py 1 張角`，与 C 侧同口径）：
  全员 **147** 人；我方 12 城中有将者为 平原 3 / 許昌 4 / 陳留 3 / 汝南 3 / 南皮 2 / 宛 2
  = **可执行者 17 人**；其余 6 座（雁門關·樂陵關·界橋·定陶·官渡·赤壁）是**關隘，本身无武将**。
- **⚠ 观感提示（非 Bug）**：点關隘时选择窗仍会是空的 —— 这是数据事实。
  选择器已内置提示「此城暫無可執行指令的武將/軍師（或本月均已行動）」，
  横幅会显示「可執行 N 人」，便于区分"真没人"与"本月已行动"。

### BUG-2 ★中：朝堂界面的"返回"跳到選擇劇本（**已修 + 已验证**）

- **现象**：朝堂时长按（=右键返回）→ 跳到**選擇劇本**界面。
- **根因**：朝堂分支 `pt.rclick` 直接 `mode = 0`，但 `app.roots` 仍指向场景栈里的
  `SC_AGE`（選擇時期）→ 显示成选择剧本。
- **用户定的口径（2026-09-17）**：① 朝堂**不要返回功能**，只能从「系統 → 回主選單」退出；
  ② **只有「開始遊戲」时才进選擇劇本**。
- **修法（已实施）**：
  1. 新增唯一出口 `goto_main_menu()`（清场景栈 + 复位 `SC_MAIN` + 清挂起命令/选择器），
     「系統 → 回主選單」改走它；
  2. 朝堂分支**忽略 rclick**（只保留"结束命令阶段"的兜底），地图右键仍回朝堂；
  3. `scene_for_command()` 之外加防线：cmd=1 映射到 `SC_AGE` 时，
     **仅当当前根是主選單（roots[0]==1）** 才放行，其它场景里的 cmd=1 一律忽略并记日志。
