## A、指令流程（骨架，优先实现）

| # | 项目 | 定稿口径 |
|---|---|---|
| A1 | 指令入口流程 | 朝堂点命令 → 切大地图 → 选城 → **玩家选择执行该指令的武将/军师** → 执行 |
| A2 | **武将月度行动限制** | 每名武将/军师**每月只能执行 1 条指令**（回合结束时清空标记）；选择界面中已行动者置灰。<br>**例外**：城池遭到攻打时，已行动过的武将/军师**仍可支援防守** |
| A3 | 取消 / 返回手势 | 平板无右键 → **长按 = 右键**（已实现，600ms / 位移<20px）；必要时再加界面「返回」按钮兜底 |
| A4 | 命令阶段菜单 | 进入命令阶段后**菜单收起**，信息条显示「XX 命令階段」引导 |
| A5 | 连续执行 | 执行后**不自动回朝堂**，可继续选下一座城；用户自己长按/返回才结束 |

## B、內政（5 项）

| # | 项目 | 定稿口径 |
|---|---|---|
| B1 | 移動 | 移动的主体 = **武将**，可**调整携带的士兵数与金钱**，**当月到达** |
| B2 | 搜索 | 不花钱；产出为 人才 / 物品 / 金钱，成功率与执行者**智力**相关。<br>**人才招募看相性**：与执行者同阵营 → 相性高可招募；中立 → 有概率失败；敌对 → 招募失败，人才回到在野状态。<br>物品搜到后**入库**，由「物品」指令统一调配。<br>**🔹甲补充（C10 裁决：相性 = 性格，同一字段）**：招揽判定只与**执行搜索者本人**与在野武将的相性接近度有关，**与君主是谁无关** —— "这个人搜不来，换一个相性近的人去搜"；<br>**物品池按城市不同**（部分稀有物只能在特定城市搜到；奥汀神枪/干将莫邪等顶级物**搜不到**），来自 甲 §25 |
| B3 | 開發 | 不花钱；开发度**上限 999**；提升量 = 执行者**智力 + 等级**综合，**等级越高按比例越高**【待测：具体系数】。<br>**🔹甲补充**：战争破坏 —— 城市被攻打后**开发度 −50**、**人口 −1%**（见 J6） |
| B4 | 人才 | 指派一名武将/军师行动；可查看**在野名单、俘虏、已调查城池的将领/军师**，进行**招募 / 劝降归顺**。<br>招募成功率遵循 **B2 的相性机制**；对俘虏**劝说次数越多，敌方君主忠诚度越低**，降到一定值即成功，成功率与"忠诚度降低量 + 相性"相关。<br>**地方城池武将/军师的忠诚度不受人才指令影响**。<br>**🔹甲补充（C12 裁决：采纳）投降判定**（按重要性）：① 目标**忠诚 < 20** 才有较高概率 ② **义理**越高越难（关羽/赵云类极难）③ 与君主**相性**越近越易 ④ 君主**威望**越高越易；"最终投降时的忠诚上限由义理+相性共同决定"（吕布可能剩 30 忠诚就降，夏侯惇要等到个位数） |
| B5 | 物品 | **不进入选城**：物品 → 列出**所有武将** → 选武将 → 三槽（武器/马/书）从物品库选择。<br>加成规则：武器加**武力**、马加**战场移速**、书加**智力**（加武力/智力走已有 `gamedata` 规则）。<br>**不消耗月度行动限制** |

## C、軍政（5 项）

| # | 项目 | 定稿口径 |
|---|---|---|
| C1 | 徵兵 | 人口与金钱减少、兵士增加；数量 = **等级×40**（= 单将带兵上限，2026-09-17 已实现，解决"武力×5 太高"）。<br>**🔹甲补充（C5 裁决）**：**每征 1 兵 = 2 金**（**2026-09-17 用户终裁 = 2**，原版为 10，我们刻意便宜 5 倍）；**无钱不能征**；**预备兵上限与城市人口正相关**（人口越多容量越大）；城市面板显示的兵力是**配给武将的兵**，不含预备兵 |
| C2 | 訓練 | **不扣金钱**；提升**士气**；士气**挂在城池整体**（非每名武将各自一份）；<br>**🔹C4 裁决**：训练量为 `5 + 武力/5 + 等级`，结果**钳到 25~30**（对齐甲 §4.3 的"训练 +25~30"）；详见 J4 |
| C3 | 戰爭 | 出兵攻打其它城池（进战场）。<br>**每名武将带兵上限 = 等级×40，等级上限 50**（C6 裁决；→ 单将最多 **2000**）。<br>出征时可在上限范围内**调整带兵数**；**行军耗时 1 个月**。<br>**🔹甲补充**：出征**最多 15 名武将**，邻近己方城市可派**援军 +15**（双方合计 ≤30）；出征前须指定**主将 + 军师**（军师决定战场可用的军师技）—— 见 §29 |
| C4 | 整備 | ①调整武将/军师所带的**兵种、阵形**；②**消耗功勋学习武将技/军师技**。<br>**🔹甲补充**：学习是**主动消费功勋**（不是升级自动获得），**严格受武力/智力/等级区间限制**（不在区间内的技能**不显示**在学习列表）；**装备临时改变属性会刷新可学列表，但已学技能永久保留、属性回落也不遗忘**；大部分技能受**地形/天气/时段**限制 |
| C5 | 調兵 | 调整**每个将领的带兵数量**：可从招募的多余士兵补充，也可在将领之间调配。<br>**🔹甲补充**：兵力不满时**平均补进各小队**；要精确调整每小队兵种/兵力需到「整備」手动安排 |

## J、数据与公式

| # | 项目 | 定稿口径 |
|---|---|---|
| J1 | **月度收入**（C1 裁决） | **每月结算一次**（原版是每半年，我们按月摊平，保留月度节奏）：<br>`收入 = (人口/100 + 开发度×2) / 6`（即原版半年税收 ÷6） |
| J2 | **人口成长**（C1 裁决） | **每月**：`成长 = (人口 × 开发度 × 3 / 100000) / 6`<br>（原版半年增长 `人口×开发度×3/100000`，除以 6 摊到月） |
