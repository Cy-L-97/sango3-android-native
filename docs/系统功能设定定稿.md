| # | 项目 | 定稿口径 |

## B、內政（5 项）

| # | 项目 | 定稿口径 |
|---|---|---|
| B1 | 移動 | 移动的主体 = **武将**，可**调整携带的士兵数与金钱**，**当月到达** |
| B2 | 搜索 | 不花钱；产出为 人才 / 物品 / 金钱，成功率与执行者**智力**相关。<br>**人才招募看相性**：与执行者同阵营 → 相性高可招募；中立 → 有概率失败；敌对 → 招募失败，人才回到在野状态。<br>**"这部分可以尝试解包获取相性数据"**（B 档任务）。物品搜到后**入库**，由「物品」指令统一调配 |
| B3 | 開發 | 不花钱；开发度**上限 999**；提升量 = 执行者**智力 + 等级**综合，**等级越高按比例越高**【待测：具体系数】 |
| B4 | 人才 | 指派一名武将/军师行动；可查看**在野名单、俘虏、已调查城池的将领/军师**，进行**招募 / 劝降归顺**。<br>招募成功率遵循 **B2 的相性机制**；对俘虏**劝说次数越多，敌方君主忠诚度越低**，降到一定值即成功，成功率与"忠诚度降低量 + 相性"相关。<br>**地方城池武将/军师的忠诚度不受人才指令影响** |
| B5 | 物品 | **不进入选城**：物品 → 列出**所有武将** → 选武将 → 三槽（武器/马/书）从物品库选择。<br>加成规则：武器加**武力**、马加**战场移速**、书加**智力**（加武力/智力走已有 `gamedata` 规则）。<br>**不消耗月度行动限制** |

## C、軍政（5 项）

| # | 项目 | 定稿口径 |
|---|---|---|
| C1 | 徵兵 | 人口与金钱减少、兵士增加；数量 = **武力 + 等级**综合（等级越高按比例越高）。<br>⚠ **当前"武力×5"太高**（初始只能带 40 兵，一个军师征的兵够分好几个将领）→ 需下调【待测：具体系数】 |
| C2 | 訓練 | **不扣金钱**；提升**士气**；士气**挂在城池整体**（非每名武将各自一份）；提升量与执行者**武力 + 等级**相关，**武力权重大**【待测：系数】 |
| C3 | 戰爭 | 出兵攻打其它城池（进战场）。<br>**每名武将带兵上限 = 等级×40，等级上限暂定 30**（→ 单将最多 1200）。<br>出征时可在上限范围内**调整带兵数**；**行军耗时 1 个月** |
| C4 | 整備 | ①调整武将/军师所带的**兵种、阵形**；②**消耗功勋学习武将技/军师技** |
| C5 | 調兵 | 调整**每个将领的带兵数量**：可从招募的多余士兵补充，也可在将领之间调配 |

## L、威望（势力声望）系统 —— 2026-09-17 用户口径

> 2. **势力威望**（本节）—— **势力级运行时值**，由战果与事件涨落，数据层**无此字段**。
