### 1.3 原版战略层整体布局（640×480 坐标空间，供对照）

```
7300 ADMAP     121, 0, 519, 345    ← 地图窗口（框）
  7301 Map     0, 0, 1024, 768     ← 整图（父坐标系 = 地图像素空间，被缩到 519×345 ≈ 0.5×）

```

⚠ **本项目与原始布局的有意偏离**（按"玩法优先 + 清晰度优先"）：我们走的是
**地图原生分辨率 1024×768 全屏 + 视口滚动**（见 `docs/项目约定.md` 三·补、六·主文件），
不是原版"缩到 519×345"。因此面板**不照搬 (408,16) 的绝对坐标**，而是按语义
**锚定到视口右上角**（右边距 16、上边距 16）。这样长屏/高分屏下位置都合理。

### 1.4 朝堂（内政阶段）—— 2026-09-16 用户指正补

**原版流程：選完勢力先進「朝堂」做內政，不是直接上大地图。**

- 背景 CG：**`Shape\AD\Background\BG001~003.shp`**（640×480 全屏，AD = 行政）。
  实解：BG001 = 金銮殿（主公居中、文武分列）、BG002 = 帐殿式朝堂（官员更多）。
- **分工（用户口径）：按势力发展规模更换，判断方式未逆向 → 自拟**：
  我方城池数 1~5 → BG001 / 6~15 → BG002 / ≥16 → BG003（实测后调）。
- **显示比例（用户实测指正）**：朝堂用 **STRETCH 整图拉伸铺满**（与 Winlator 实机截图
  一致），**不用 EXTEND** —— EXTEND 会镜像出重复的柱子、比例别扭。
- 本项目流程（首版）：開局 → **朝堂**（640×480 逻辑画布 + STRETCH）：
  左侧行政主選單 + 右上城池信息面板（"当前城"固定为我方第一座城）+ 信息条显示月份；
  **点命令 → 切大地图选城执行（见第五节指令流）**；**「確定」= 月度结算 → 切大地图**；
  大地图**右键/Back → 回朝堂**；朝堂**右键 → 回主菜单**；「系統 → 回主選單」同。
- 朝堂视图由 `strategy_scene` 内实现（`s3_strategy_set_view` / `set_court_bg` /
  `select` / `set_month`），不另起场景文件 —— 面板/HUD 与地图视图共用一套。
- ⚠ **选君主界面也待重做**（用户 2026-09-16 附原版截图）：原版是**直接在大地图上**
  展示 —— 左侧君主列表（名/聲/武/智/忠/士），选中君主的城池在地图上高亮（插旗），
  右侧城池信息面板，底部君主统计栏（城數/關口數/武將數/總兵數/人口/金錢）+ 肖像。
  与「势力插旗」（S6）同源，一并做。

## 四、实现方案

### 4.1 数据层（`sango3app.c`，扩 `load_cities`）
1. 解析 `City.ini` → 建 `城名 → Size` 索引（备用解析 `Neighbors`）。
2. 解析 `General02.ini` → `城名 → 武将数` 计数（`CityN` 中逗号前的部分匹配城名；
   带 `,野` 的仍算该城在野人才，**计入**「武將」）。
3. 解析 `Nation.ini` → `(我方君主, 对方君主) → 友好度`。
4. 把上面三项 + `City0N.ini` 的 `Lord/People/Money/Development/ReserveForce`
   一起塞进 `StratCity`。

### 4.2 渲染层（`strategy_scene.c`）
- 新增 `S3CityInfo` 字段到 `StratCity`（people/money/dev/reserve/size/n_generals/friend/lord）。
- 新增 `s3_strategy_load_panel(s, "Shape\\AD\\Base\\CityInfo.shp")`：
  复用已有的 `read_asset` 回调 + `shp_decode`，缓存 `ShpImage`（同 `map` 的做法）。
- 选中城池时，在视口右上角 `(view_w-98-16, 16)` 贴面板图（`sango3_canvas_blit`，zoom=1）
  + 九行值文本（`draw_text` 回调，值区 x = 面板x+35，行距 18）。
- 面板出现时**不遮挡**地图拖动（仅绘制，不参与命中）。

### 4.3 交互层
- 已有：点击城池 → `sel`。本步：`sel >= 0` 时自动弹面板。
- 再点空白 → `sel = -1`（收起面板）—— 需要给 `on_click` 加"点空处清除选择"。

### 几何（实测校准）

| 量 | 值 | 依据 |
|---|---|---|
| 按钮 | 121×29 | `Menu.ini` 8001~8007 的 `Range` |
| 按钮纵向间距 | 33 | 7 个按钮 y = 0,33,66,99,132,165,198 → 末底 = **227** = 8000 的 `Range` 高 ✓ |
