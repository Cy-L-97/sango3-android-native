### 7.4 过程中修掉的一处

**外交叠加层吞掉了"切到大地图"这一步**：处理块排在 `else if (g_admin_map)` **之前**且直接 `continue`，
导致 `diplo_start` 设的 `g_admin_map = 1` 永远不被消费 → **界面停在朝堂、看不到选国家**
（实测截图发现）。修法：在该块开头先把 `g_admin_map` 消费掉（`if (g_admin_map) { g_admin_map = 0; if (court) mode = 4; }`）。
