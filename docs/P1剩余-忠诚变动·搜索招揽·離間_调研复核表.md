## 一、M-0 等级差加速（已裁定 → 本批实现）

| 项 | 内容 |
|---|---|
| 定稿口径 | M4：`d = 对手势力平均等级 − 自身等级`；`d ≥ 8 → ×2`、`d ≥ 15 → ×3`；**仅落后方**，封顶 ×3 |
| 当前实现 | **未实现**（`monthly_exp_of()` 只乘难度系数 `g_exp_diff_pct`） |
| **拟定实现** | ① 每次月度结算前算一次 **`E = 全部「非我方且非在野」武将的等级均值`**；<br>② 对**我方**武将：`d = E − 该将等级`，`d ≥ 15 → ×3`、`d ≥ 8 → ×2`，否则 ×1；<br>③ 他方/在野武将**维持 ×1**（否则两边同时加速会互相抵消，且会让 AI 滚雪球）。 |
| ⚠ **实现注（待你点头）** | 把"仅落后方"落地为**"只给我方加乘"** —— 理由：需求① 的目标是"我方将领自动升级"追平 AI；双向加速等于常数缩放，无意义。若你希望 AI 也享受该加速，说一声即可（一行开关）。 |
| 常量 | `S3_LEVELGAP_MULT_1 = 2` / `S3_LEVELGAP_MULT_2 = 3` · 阈值 `S3_LEVELGAP_D1 = 8` / `S3_LEVELGAP_D2 = 15`（留常量便于实测调） |
