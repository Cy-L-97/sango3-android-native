## 一、`Map\Map001.blk` ~ `Map067.blk`（67 个）

### 文件结构

```
偏移 0   7 字节  magic = "BlkData"
偏移 7   4 字节  u32 rows（行数）
偏移 11  4 字节  u32 第二字段（实测 Map001=26 ↔ cols=51；Map007=22 ↔ cols=43，
                 疑似 cols+1 或"块数"，**含义待定**）
偏移 15  数据段：每行 = cols × 4 字节
```

- `cols = 数据段长度 / 4 / rows`（实测：Map001 = 51×28、Map002/3 = 59×30、
  Map005/6 = 59×30、Map007 = 43×26）
- **每格 4 字节，第 1 字节 = 地形属性（1..13）**，其余 3 字节含义待定
  （byte0 ∈ 0..5、byte2 ∈ 0..3、byte3 ∈ 0..255，疑似变体/高度/朝向）

## 二、瓦片（`Shape\SF\Map\*.shp`，`SFMap.ini` 的 `[graphics]`，148 条）

- 瓦片尺寸 **96 × 36**（等距菱形；文件是"逐行扫描"格式：每行 = 4 字节头 +
  96×2 字节 RGB565，`0xFFFF` 为透明键）
- `[graphics]` 是**瓦片编号 → 文件名**表（编号 1..193，含重复/多段）
- **接缝体系**：文件名前缀表示"从 X 过渡到 Y"，后缀 01..09 表示方位，例如
  `PLN_GRS01` = 土地围草地上、`GRS_PLN03` = 草地围土地右。
  即：**渲染时按"属性 + 邻接"选瓦片**，不是单纯按属性查一张图。
- 各属性**基础（纯色）瓦片族**（5 个变体，编号见 graphics 表）：

| 属性 | 基础族 | 属性 | 基础族 |
|---|---|---|---|
| 1 土地 | `Plane001~005` | 6 雪地 | `ssss0~2` |
| 2 草地 | `gggg0~4` | 7 街道/碎石 | `PLN_STR09` |
| 4 沙漠 | `PLN_DRT09` | 9 山地 | `PLN_MTN01~05` |
| 5 水区 | `WTR01~05` | 10~13 城/房舍 | 用 `AD\Btn\City\*` 图标（非瓦片） |

- `tam00/tal00/tar00/tbm00/tbl00/tbr00` = 城门（↙↗ / ↖↘ 两种朝向）；
  `STR-HUS01~06` = 街道-房舍；`PLS-R/PLS-L` = 特殊接缝。

## 三、城市与地图界面（`Setting\MenuMap.ini`）

- `[WINDOW] ID = 7300`（`WND_CLASS_ADMAP`）＝ 战略地图根，Range `121,0,519,345`，
  子窗口 7301（Map，声明 **1024×768**）+ 7302（城名层）+ **7303..7372 = 70 个城市**
- 城市窗口：`Class = WND_CLASS_CITYBUTTON`，`Range = x, y, w, h`（**地图坐标系**），
  `Icon/Check` 指定图标（大城/中城/小城/关卡 + 激活态/可移动态），`Command = 101..`
- 城市图标素材：`Shape\AD\Btn\City\City01-1`（大城）`City02-1`（中城）`City03-1`（小城）
  `City04-1`（关卡），激活态 `City01_Active01…`

### 城市 ↔ 网格映射（**已用数据验证**）

```
cell_col = city_x * cols / 1024
cell_row = city_y * rows / 768
```

实测（70 个城市，属性 ≠ 5 水 即算落在陆地）：

| 地图 | 网格 | 命中 | 备注 |
|---|---|---|---|
| Map001 | 51×28 | 53/70 (76%) | |
| Map002 | 59×30 | 58/70 (83%) | |
| Map004 | 59×30 | 65/70 (93%) | |
| **Map005** | 59×30 | **70/70 (100%)** | 属性分布自然（土地26/草地10/森林11/街道8…） |

→ **矩形网格映射成立**；`MapNNN` 的编号与剧本编号存在对应关系（待最终确认）。

## 六、插旗与城名层（I1 / I3，2026-09-17 实现）

### 6.1 势力旗号（`Nation.ini` 的 `Flag`）

- 段落名是 **`NATION{n}{xx}`**：**首位数字 = 剧本号**（`NATION100~117` = 剧本 1 的 18 个势力；
  `NATION200~` = 剧本 2 …，共 78 段）。**必须按剧本过滤**，否则会把别的剧本的同名势力串进来。
- 字段：`Lord`（君主）/ `Flag`（旗号 1~35）/ `BGM` / `Friendship`（对 17 个对手的友好度）。
- 城池归属链：**城市太守（`City0N.ini` 的 `Lord`）→ 该势力的 `Flag`** → 绘制时按号取色。
- 实测（剧本 1）：襄平·劉備=**2** · 北平·公孫瓚=**10** · 代縣·劉焉=**23** · 晉陽·袁紹=**7** ·
  南皮/平原·張角=**5** ✅ 与 `Nation.ini` 逐项吻合。

### 6.2 ⚠ 原版旗位图尚未破解（`Shape\AD\Btn\Flag\Flag{势力}{状态}.SHP`，32×6 = 192 张）

- 该素材是 **`type=1`**，与常规 `type=0`（「一行一帧」、`u16 flags + u16 span + RGB565`）**不同版式**：
  - 头部（23×29，`0x24` 起 3 个 u32 = `58 / 358 / 660`，`0x4C` 起是**逐行偏移表**，步长 16、
    共 29 项 → 行数据区 196..660）；
  - **660 之后是 32 位像素流**（实测 `44 44 44 ff 35 35 35 ff …`，即 RGBA8888，A 恒为 FF，
    灰度渐变 = 旗杆的明暗），不是 RGB565；
  - 6 个状态号（0000~0005）之间**差异 1000+ 字节**，是与否为动画帧/颜色变体尚无定论。
- **取舍（已按「玩法优先，不逐像素复刻」降级）**：当前用**程序化旗帜**（旗杆 + 矩形旗面，
  颜色按 `Flag` 号取 32 色板），达成"一眼看出城池归属"的玩法目的。
  破解后只需把 `draw_city_flag()` 换成贴图，其余逻辑不动 → 记入 T13。

### 6.3 城名层（`Shape\AD\Base\CitiesName.shp`）

- 头部 `type=0 / w=1024 / h=768`，但帧偏移表的值只差 **2**（`3108, 3110, 3112 …`），
  与「一行一帧、行内 `u16 flags + u16 span + 像素`」的常规版式**对不上**（文件仅 58KB，
  也远小于 1024×768 的常规体积）→ 版式特殊，同样记入 T13。
- **取舍（已实施）**：I3 **不接这幅烘焙位图，改用引擎字体直接画城名**。理由：
  ① 省掉一次逆向；② 城名走「简中显示层」，与全项目"简中优先"一致（位图是繁体，接了反而两套）；
  ③ 名称数据本就在 `MenuMap.ini` 的 `Comment` 里，零成本。
  实现：城名画在城池图标**下方**（深色底衬 + 我方金色/选中红色描边），旗画在图标**左上**，
  两者都不遮图标本身。
