# 三国群英传3 · 安卓原生移植项目

把《三国群英传3》（Steam 正版）通过**自研引擎重写**的方式移植为安卓原生应用，并实现 5 项玩法改造。

## 路线

**A 档 → B 档 递进**

- **A 档（2~4 周）**：可运行的原生原型 —— 加载原版 PAK 素材、开局、打一场简化战斗、5 项需求全部生效。demo 保真度，但代码全部是 B 档的地基。
- **B 档（4~6 个月）**：逐系统对照原版校准，达成忠实还原。

> 已排除的方案：Winlator / Wine+Box64 兼容层路线（用户明确要求原生运行）。

## 5 项定制需求

| # | 需求 | 原生方案下的实现 |
|---|---|---|
| 1 | 我方将领跟随时间自动升级 | 玩家/电脑共用同一升级函数 |
| 2 | 士兵上限 400 → 1000 | 引擎配置常量 |
| 3 | 必杀技携带数无限制 | 自建技能数据结构，不受原版位掩码限制 |
| 4 | 我方武力≥80 自动学习必杀技 | 学习规则为自写判断逻辑 |
| 5 | 素材高清化 | 引擎原生高分辨率渲染 + AI 超分管线 |

## 技术栈

C++20 · SDL2 · OpenGL ES 3.0 · CMake · Android NDK（一套代码：Windows 调试版 + Android 交付版）

辅助：Ghidra（逆向参考原版逻辑）· SangoExplorer / RPGViewer（素材格式对照）· Real-ESRGAN（素材超分）

## 目录结构（规划）

```
/                     项目根
├── docs/             方案文档、技术笔记、逆向记录
├── engine/           引擎核心（资源/渲染/音频/输入）
├── game/             游戏逻辑（内政/大地图/战斗/AI）
├── tools/            离线工具（PAK 解包、素材超分、数据表转换）
└── .workbuddy/       项目记忆（进度日志，随仓库同步）
```

**注意**：`game/` 目录名与 .gitignore 中的原版素材目录同名冲突风险 —— 后续落地时以 `src/game/` 存放代码，原版素材一律放在仓库外并用配置指向。

## 双机开发（周末台式机 + 工作日笔记本）

- 代码、文档、`.workbuddy/memory` 进度日志**全部随 Git 同步**；
- 游戏原版素材与素材大文件**不入库**，两台机器各自从本地正版游戏读取（用配置文件指定路径）；
- 收工前：`git add -A && git commit && git push`；开工时：`git pull`。

详见 `换机开工清单.md`。
