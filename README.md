# 三国群英传3 · 安卓原生移植项目

把《三国群英传3》（Steam 正版）通过**自研引擎重写**的方式移植为安卓原生应用，并实现 5 项玩法改造。

> 项目规则、口径与红线见 [`docs/项目约定.md`](docs/项目约定.md)（长期规范，开工先读）。

## 路线

**A 档 → B 档 递进**

- **A 档（2~4 周）**：可运行的原生原型 —— 加载原版 PAK 素材、开局、打一场简化战斗、5 项需求全部生效。demo 保真度，但代码全部是 B 档的地基。
- **B 档（4~6 个月）**：逐系统对照原版校准，达成忠实还原。

> 已排除的方案：Winlator / Wine+Box64 兼容层路线（用户明确要求原生运行）。

## 5 项定制需求

| # | 需求 | 原生方案下的实现 |
|---|---|---|
| 1 | 我方将领跟随时间自动升级 | 玩家/电脑共用同一升级函数 |
| 2 | 士兵上限 400 → 1000 | 引擎配置常量 |
| 3 | 必杀技携带数无限制 | 自建技能数据结构，不受原版位掩码限制 |
| 4 | 我方攻击力≥80 自动学习必杀技 | 自写运行时规则：**当前攻击力（基础武力 + 武器加成）≥ 80** 即授予，敌我一致；攻击力回落**不收回**。详见 `docs/必杀技学习规则.md` |
| 5 | 素材高清化 | 素材分级替换（1×/2×/3×/4×），引擎自动选档 |

## 显示语言（默认简体中文）

用户口径「不必完全复刻原版，优先支持简中显示」。游戏数据是 Big5 繁体，因此设**显示语言层**：

- 离线生成繁→简映射表 `lang_hant2hans.json`（OpenCC t2s，语料 = 游戏自身全部文本；
  **1999 繁体字 / 1964 简体字，713 字发生转换，冲突 0**）；
- 引擎侧**只查表**，无运行时依赖；繁/简是一个开关，不是两套代码；
- 文本渲染两种模式：**矢量（默认，覆盖 100%）** / **像素（可选，简中覆盖 99.75%）**；
- 像素模式的缺字由回退链兜底 → **任何文本都不出方框**。

## 关键事实基线（实测，非推测）

| 项 | 结论 |
|---|---|
| 逻辑坐标空间 | **640×480**（`Menu.ini` 根窗口 `Range=0,0,640,480`），且与素材像素 **1:1** |
| 分辨率配置 | 数据层**不存在** —— 原版硬编码在 exe 内，我们可自由定义 |
| PAK 格式 | `PAKS` + 64 字节定长索引；Sango3.PAK 24,477 条素材 / Update.PAK 87 条数据与脚本 |
| SHP 格式 | `TLHS` + 帧偏移表 + **RGB565 直色**（无调色板） |
| 规则数据 | 全在可解包的 Big5 INI 里：421 武将 / 9 兵种 / 125 武将技 / 103 物品 |
| 必杀技 | `SuperAttack` 字段取值 1~8（原版数据本身存过多个，如吕布 `5,8`）；有 **16 名武将基础武力 < 80 却自带必杀技**，证明「开局预设」是独立于「达标自动学」的第二来源 |
| 装备加成 | `General01.ini` 有 `Weapon`/`Book`/`Horse` 三个装备槽（**存物品名，不是索引**）；`Thing.ini` 的 `Increment` 是加成值。**只有武器(Type=2) 加武力 +1~+20**，书加智力/技力/体力上限，马加速度 |
| 攻击力公式 | `当前攻击力 = 基础武力 + 武器加成`（武器上限 +20，故基础武力 ≥60 者理论上都能跨过 80） |
| 士兵上限 400 | **不在**任何数据文件里（`Thing.ini` 的 `Count=400` 是物品数量），属 exe 硬编码 → 我们自己的引擎里就是一个变量 |
| 素材覆盖机制 | 游戏优先读根目录外置 `Setting\` 与 `Shape\`（第三方"修复+增强补丁"已实证生效） |

## 分辨率与高清化

**交付标准：最低 2K（2560×1440），设计上限 4K。** 完整规范见 **[`docs/分辨率与高清化架构.md`](docs/分辨率与高清化架构.md)**。

四条铁律：
1. 玩法逻辑 / UI 布局 / 点击命中一律用 **640×480 逻辑坐标**，代码里不出现物理像素常量；
2. 物理分辨率只出现在视口变换层（`engine/src/render.c`）；
3. 素材按 `1×/2×/3×/4×` 分级，引擎按输出分辨率自动选档 —— **高清化因此是一次纯资源替换，不动代码**；
4. 文本渲染统一经「显示语言层」，业务代码不直接接触 Big5 原文。

## 技术栈

C11（数据层 / 渲染核心）+ C++17（游戏逻辑）· SDL2 · CMake + Ninja + MSVC · 目标 Android NDK
（一套代码：Windows 调试版 + Android 交付版）

辅助：Ghidra（逆向参考原版逻辑）· SangoExplorer / RPGViewer（素材格式对照）· Real-ESRGAN（素材超分）

## 常用命令

```bash
# 构建（CMake + Ninja + MSVC，封装了"无 vcvars"环境构造）
python tools/build_pc.py
python tools/build_pc.py --reconfigure     # CMake 结构变更后

# 依赖部署（换机器时执行一次）
python tools/fetch_sdl.py && python tools/setup_sdl.py
python tools/fetch_fonts.py && python tools/setup_fonts.py    # 字体已入库，通常无需重跑

# 字体与显示语言
python tools/build_lang_table.py       # 生成繁→简映射表 + 繁简字符集（换游戏版本后重跑）
python tools/check_font_coverage.py    # 用游戏全部文本量化覆盖率（换字体后必跑）
python tools/render_font_preview.py    # 渲染验收图（含简中转换与缺字回退验证）

# 数据字典（从本机正版重新生成）
python tools/build_data.py

# 出图验证
python tools/render_gallery.py    # M0 素材图库（617 张）
python tools/render_scene.py      # 分辨率矩阵：640×480 / 1080p / 2K / 4K × 三种滤镜
```
